# Bomberman

## Description

Jeu où il faut avancer sur une map en détruisant des blocs et tuant des monstres avec des bombes pour gagner la partie.

## Techno

Unity avec C#

## Tester 

Pour tester le jeu et voir l'avancement, il faudra voire dans la Releases.

Vous n'avez pas besoins d'avoir Unity sur votre PC pour tester le jeu.
